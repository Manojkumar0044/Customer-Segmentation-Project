# Customer Segmentation Project

## Objective
Segment customers using demographic and purchasing behavior data and identify actionable customer groups.

## Tools
- Python
- Pandas
- Scikit-learn
- Excel
- Power BI-ready CSV data

## Technique
K-Means Clustering with 4 clusters.

## Features Used
Age, Annual Income, Spending Score, Purchase Frequency, Average Order Value.

## Model Evaluation
Silhouette Score: 0.400

## Files
- Customer_Segmentation_Data.csv — cleaned customer dataset
- Customer_Segment_Summary.csv — segment-level analysis
- Customer_Segmentation_Project.xlsx — Excel dashboard, data, analysis and insights
- customer_segmentation.py — Python clustering script
- Customer_Segmentation_Report.docx — project report

## Dashboard
The Excel workbook contains KPI cards, segment distribution, customer counts, estimated spend, and business recommendations.
